# qurious-crafting-log

モンスターハンターの錬成結果を記録・検索するためのWindowsデスクトップアプリです。
NX Macro Controllerの錬成結果や、
Switchで撮った「傀異強化結果」画面のスクリーンショット（`*.jpg`。8bitで自動で撮ったものなど）を
取り込んで、条件を指定して検索できるようにします。

## ダウンロード・インストール

1. [Releases](../../releases) から最新の `qurious-crafting-log-setup.exe` をダウンロードします。
2. ダウンロードしたexeを実行し、案内に従ってインストールします。
3. インストール後、スタートメニューから起動できます。

## できること

- **取込**：次の2通りの方法で錬成結果を取り込み、練成している防具ごとに記録
  - クリップボードにコピーした錬成結果（NXのログ画面の文字列）を貼り付けで取込
  - Switchで撮った「傀異強化結果」画面のスクリーンショットを読み取って取込
- **検索**：スキル集合（保存・呼び出し可能）、コスト、耐性、スキル欠けの有無、取込日時、対象バッチなどで絞り込み検索
- **履歴**：取込バッチ一覧の閲覧・削除、防具ごとの合計練成数、取込時に見つかった問題（エラー）の確認
- **回収確認**：検索結果で「回収」にチェックを付けると、どのタブを見ていても内容を確認できるサイドパネルで管理
- **設定**：
  - 起動時のアップデート確認のON/OFF
  - 防具ごとの検索初期設定（取込直後に自動で検索タブへ移動する際の初期条件）
  - 検索結果のスキル文字色（プラス/マイナス）のカスタマイズ
  - 取り込んだ錬成結果や設定のバックアップ・復元（データを1つのファイルに保存し、あとで元に戻せます）
- **自動アップデート確認**：起動時にGitHub Releasesの最新版を確認し、新しいバージョンがあれば通知

## 練成画像からの取込

Switchで撮った「傀異強化結果」画面のスクリーンショット（`*.jpg`）から、
スロット・スキルとレベル・耐性・所持ゼニーを読み取って取り込みます。

### 使い方

1. 1回の連続した記録の画像を、1つのフォルダにまとめます（ファイル名はSwitchが付けたままにしてください）。
2. 取込タブで練成している防具を選び、「練成画像から取込（8bit）」の各欄を入力します。
   一度入力すると防具ごとに記憶されます。

   | 欄 | 内容 |
   |---|---|
   | 初期スロット | 練成前の防具のスロットのレベルの合計（例：Lv3・Lv2・Lv1 なら 6） |
   | 1回のゼニー | 1回の練成で減るゼニー（4000 または 6000） |
   | 抽選テーブル | 防具の抽選テーブル（5 または 6。分からなければ「なし（不明）」） |
   | 防具が元から持つスキル | `攻撃:2,火事場力:3` のように「スキル名:元のLv」をカンマ区切りで入力 |

3. 「フォルダを選択」で画像のフォルダを選び、「画像から取込」を押します。
4. アプリが初めて見る表示（スキル名・数字・スロット）があると、その部分の画像と選択肢が出ます。
   画像を見て、正しいもの（スキル名・数字・追加スロット数）を選んでください。
   選んだ内容は記憶され、次回から同じ表示は自動で読み取ります。

### 注意点

- 対応している画像は **1280x720**（Switch標準のスクリーンショット）だけです。
  別の解像度の画像が1枚でも含まれていると、取込を中断します。
- 結果画面以外の画像は自動で除かれます。
- スキルが4つ以上付いた結果は、4つ目以降が画面に写りません。写っていない分は
  「何らかのマイナススキル」または「不明」として記録します。
- 読み取りの矛盾（ありえない増減など）や、抽選の仕様では作れない結果（読み間違いの疑い）は、
  履歴タブの「エラー」欄から確認できます。該当する画像を見て確かめてください。
- 初期スロット・防具が元から持つスキルを間違えると、スロット数や写っていないスキルの判定がずれます。
- 読み取りの速さの目安は、USB接続のSDカードから約1万枚で約80秒です。

## データの保存場所

`%LOCALAPPDATA%\QuriousCraftingLog\qurious_crafting_log.db`（SQLite）

練成画像の取込で選んで記憶させた内容は、同じフォルダの `ocr_templates` に保存されます。

## 開発者向け

### セットアップ

```powershell
python -m venv .venv
.venv\Scripts\pip install -e .[dev]
```

### アプリの起動

```powershell
.venv\Scripts\flet run app/main.py
```

### テスト

```powershell
.venv\Scripts\pytest
```

### Windows向けビルド（インストーラー作成）

```powershell
pwsh -File scripts\build_release.ps1
```

`build\installer\qurious-crafting-log-setup.exe` が生成されます。コミット済みの内容を `C:\build\qcl` に書き出して
ビルドします（プロジェクトのフォルダで直接ビルドすると、フォルダのパスが exe の中に記録されるため）。

新しいバージョンをリリースする際は、`app/version.py` の `APP_VERSION` を、GitHub Releasesの
タグ名と一致するように更新してください（アプリ内の更新チェック機能がこの値を参照します）。
