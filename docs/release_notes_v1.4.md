v1.3からの主な変更点です。

## 新機能

- **練成画像からの取込（8bit）**
  Switchで撮った「傀異強化結果」画面のスクリーンショット（`*.jpg`）のフォルダを選ぶと、
  スロット・スキルとレベル・耐性・所持ゼニーを読み取って取り込めるようになりました。
  取込タブの「練成画像から取込（8bit）」から実行します。
  - 対応している画像は 1280x720（Switch標準のスクリーンショット）だけです。別の解像度の画像が
    含まれていると取込を中断します。
  - 初期スロット・1回のゼニー・抽選テーブル・防具が元から持つスキルを防具ごとに入力します
    （一度入力すると記憶されます。ギルパレ脚・クシャ胴・マッスル腕は初期値が入っています）。
  - アプリが初めて見る表示（スキル名・数字・スロット）があると、その部分の画像と選択肢が出ます。
    画像を見て正しいもの（スキル名・数字・追加スロット数）を選ぶと、次回から同じ表示は自動で読み取ります。
  - 結果画面以外の画像は自動で除かれます。
  - 読み取りの速さの目安は、USB接続のSDカードから約1万枚で約1分半です。

- **写っていないスキルの記録**
  スキルが4つ以上付いた結果は、4つ目以降が画面に写りません。写っていない分は、並び順と抽選の仕様から
  判定して「何らかのマイナススキル」「不明（マイナススキルが一個以上）」「不明」のいずれかとして記録します。

- **画像取込のエラーの確認**
  履歴タブの「エラー」欄に、画像取込で見つかった問題を表示します。
  - 画像読み取りの矛盾（要確認）：ありえない増減や、防具が元から持たないスキルのマイナスなど
  - 仕様違反（要確認）：抽選の仕様では作れない結果（読み間違いの疑い。抽選テーブルが「なし」の防具では調べません）

- **取込元の表示**
  履歴タブの取込履歴と、検索タブの対象バッチの選択肢に、取込元（nxまたは8bit）を表示します。

## 変更

- **検索結果に防具の名前を表示**
  検索結果の「バッチ」の列を「バッチ・防具」にし、「#34 ギルパレ脚」のように表示します。
  あわせて取込日時を月日と時分だけの表示にしました（マウスを乗せると元の日時が出ます）。
- **検索結果のスキルの並び順を、ゲームの結果画面と同じ順に変更**
  これまでのスキル名順から、プラスのスキルをコストの高い順 → マイナスのスキル → 写っていないスキルの印、の順にしました。
- 装備の追加時に、練成画像からの取込で使う設定も入力できるようにしました。

## 注意

- 練成画像の読み取りを同梱したため、インストーラーのサイズが大きくなっています（約25MB → 約67MB）。
- 既存のデータ（取込済みのバッチ・スキル集合・設定）は、そのまま引き継がれます。
- 練成画像の取込で選んで記憶させた内容は `%LOCALAPPDATA%\QuriousCraftingLog\ocr_templates` に保存されます。

## ダウンロード・インストール

`qurious-crafting-log-setup.exe` をダウンロードして実行してください。
