v1.4からの変更点です。

## 不具合の修正

- **「フォルダを選択」でエラーになることがある問題を修正**
  練成画像のフォルダを一度選んだ後、そのフォルダがあったSDカードやUSBメモリを抜いた状態（または別のドライブ文字で
  接続した状態）で「フォルダを選択」を押すと、「指定されたドライブが見つかりません」というエラーが出て、
  フォルダを選べなくなっていました。

## 変更

- **レベルの増減のチェックを、スキルごとの最大レベルに合わせて変更**
  これまでは、スキルに関係なく「±4 を超える増減」を画像読み取りの矛盾としていました。
  今後は、スキルごとの最大レベル（防具が元から持つスキルは、元のレベルを引いた分）を超えたときに矛盾とします。
- **読み取る画像の範囲を画面に表示**
  読み取るのは、選んだフォルダの直下にある画像だけです（サブフォルダの中は読み取りません）。
  このことを取込タブに表示し、直下に画像がないフォルダを選んだときにも案内を出すようにしました。

## ダウンロード・インストール

`qurious-crafting-log-setup.exe` をダウンロードして実行してください。
