## 不具合の修正

- **練成画像の取込で、すべての画像が「結果画面以外」または「読込失敗」になることがある問題を修正**
  フォルダの場所（パス）に日本語などの文字が入っていると、画像や読み取り用のデータを開けませんでした。
  - Windowsのユーザー名（`C:\Users\` の下のフォルダ名）に日本語などが入っていると、すべての画像が「結果画面以外」になっていました。
  - 画像を置いたフォルダの名前や、その上のフォルダの名前に日本語などが入っていると、すべての画像が「読込失敗」になっていました。

## 注意

- **TVモード（ドックに挿した状態）で撮った画像では、スキル名の選択が多く出ます**
  アプリに入っている読み取り用のデータは、携帯モードで撮った画像から作っています。TVモードの画像は文字の描かれ方が少し違うため、スキル名が「初めて見る表示」として扱われ、画像と選択肢が出ます。
  一度選べば、次回から同じ表示は自動で読み取ります。防御力・耐性・スロット・所持ゼニーは、そのまま読み取れます。

## ダウンロード・インストール

`qurious-crafting-log-setup.exe` をダウンロードして実行してください。
