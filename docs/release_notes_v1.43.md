v1.42からの変更点です。練成画像からの取込（8bit）の進め方が変わりました。

## 不具合の修正

- **画像からの取込が「invalid literal for int() with base 10: '+1+'」などのエラーで止まる問題を修正**
  数字の表示に違うラベル（「+」など）を選ぶと、その後の取込がすべて止まっていました。
  今回から、読み取りにはアプリに入っている見本だけを使います。以前に選んだ内容は使わないので、
  この状態になっていた場合も、そのまま取り込めるようになります。

## 変更

- **読み取れない表示があっても、選択肢は出なくなりました**
  これまでは、アプリが初めて見る表示（スキル名・数字・スロット）があると、画像と選択肢を出して選んでもらっていました。
  今後は、読み取れない値があった画像は取り込まず（検索にも出ません）、その画像を見て確認してもらいます。
  - 取込が終わると「読めなかった画像 ○枚 を見る」ボタンが出ます。何回目の練成か・ゼニー・画像を、1枚ずつ表示します。
  - 画像のファイル名を押すと、エクスプローラーでその画像の場所を開きます。
  - 履歴タブの「エラー」欄からも、後から見られます。
  - 画像は取り込んだときのフォルダから表示します。フォルダを移動・削除すると表示できません。
  - 初期スロットが 3・6 以外の防具では、スロットの表示についてだけ、これまでどおり選択肢が出ます。
- **ドックに入れて撮った画像（TVモード）は、取り込めなくなりました**
  ドックに入れた状態では、テレビに繋いでいなくても、文字の描かれ方が変わります。これまでは選択肢から選べば
  取り込めましたが、選択肢を出さなくなったので、対応しているのは携帯モードで撮った画像だけです。
  ドックで撮った画像のフォルダを選ぶと、案内を出して取込を止めます。Switchをドックから外して撮ってください。
- **読み取れる画像を増やしました**
  耐性が「+4」のときに出る火花や、光の粒で、読み取れなくなっていた画像を減らしました。
- **履歴タブの「エラー」欄を見やすくしました**
  - 撮れていない回（飛ばされている練成）が、「画像読み取りの矛盾」にも重ねて出ていたのをやめました
    （これまでに取り込んだバッチの表示も変わります）。
  - 飛ばされている練成に、前後の画像のファイル名を出します（今回以降に取り込んだバッチでは、押すと画像の場所を開きます）。
  - それぞれの見出しに件数を出します。

## ダウンロード・インストール

`qurious-crafting-log-setup.exe` をダウンロードして実行してください。
