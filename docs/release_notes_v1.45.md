v1.44からの変更点です。

## 不具合の修正

- **同じスキルが2回入っている結果があると、取込が途中で止まったまま固まる問題を修正**
  - テキスト（NXのログ）の取込: そのような結果が1つでもあると、ログ全体を取り込まずに、その結果を表示します。
    ゲーム画面の明るさが適切でないときに起こり、他の結果も正しくない可能性が高いためです。
  - 画像の取込: その画像だけを取り込まずに、確認が必要な画像として表示します。ほかの画像は取り込みます。
  - 取込の途中で思わぬ失敗が起きたときも、画面を固めずに、失敗した結果を表示します（そのときは何も保存しません）。

## 変更

- **検索タブに「練成回数で移動」を追加しました**
  練成回数を入れると、その回の結果があるページに移動し、その行を目立たせます。バッチを1つ選んで検索したときに
  使えます（練成回数はバッチごとに1から数えるためです）。その回が検索結果に無いときは、理由（検索条件に合わない、
  確認が必要な画像で取り込んでいない、など）を表示します。
  これまでの「件数で移動」は、検索結果の上から何件目かを指定するものです。取り込んでいない回があると、練成回数とは
ずれます。
- **検索結果を「コストが高い順」で並べたとき、同じコストの結果は練成順に並ぶようにしました**
  これまでは、同じコストの結果どうしの順番が決まっていませんでした。
- **画像の読み取りの見本を追加しました**
  マッスル腕の携帯モードで、これまで読めなかった形のスキル名・スロット・数字の見本を入れました。
- **取込を中止したときの案内文を、短くまとめました**
